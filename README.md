# คลังสินค้า · แดชบอร์ดเรียลไทม์

โปรเจกต์ React (Vite) พร้อม deploy ขึ้นเว็บจริงผ่าน Vercel หรือ Netlify

## ⚠️ ข้อควรรู้ก่อน deploy

ระบบเก็บข้อมูล (สต๊อก + ประวัติรับ-จ่าย) ไว้ใน **localStorage ของเบราว์เซอร์** แต่ละเครื่อง/แต่ละคนที่เปิดเว็บนี้จะเห็นข้อมูลของตัวเองเท่านั้น ไม่ใช่ข้อมูลที่แชร์กันทั้งทีม — ถ้าต้องการให้หลายคนเห็นข้อมูลชุดเดียวกันแบบเรียลไทม์ (เช่น ทีมคลังสินค้าหลายคน) จะต้องต่อกับฐานข้อมูลจริง (เช่น Supabase, Firebase) เพิ่มเติม บอกได้เลยถ้าต้องการให้ช่วยทำส่วนนี้ต่อ

## รันดูบนเครื่องตัวเองก่อน (ไม่บังคับ)

ต้องติดตั้ง [Node.js](https://nodejs.org) เวอร์ชัน 18 ขึ้นไปก่อน

```bash
npm install
npm run dev
```

จะได้ลิงก์ `http://localhost:5173` เปิดดูในเบราว์เซอร์ได้ทันที

## Deploy ขึ้น Vercel (แนะนำ ง่ายสุด)

1. สร้างบัญชี GitHub (ถ้ายังไม่มี) แล้วสร้าง repository ใหม่
2. อัปโหลดโฟลเดอร์นี้ทั้งหมดขึ้น GitHub repository นั้น (ลาก-วางไฟล์ผ่านหน้าเว็บ GitHub ได้เลย หรือใช้คำสั่ง git ก็ได้)
3. ไปที่ [vercel.com](https://vercel.com) สมัคร/ล็อกอินด้วยบัญชี GitHub
4. กด **Add New → Project** แล้วเลือก repository ที่เพิ่งอัปโหลด
5. Vercel จะตรวจจับว่าเป็นโปรเจกต์ Vite ให้อัตโนมัติ (Framework Preset: Vite) — ไม่ต้องแก้ค่าอะไร กด **Deploy** ได้เลย
6. รอประมาณ 1 นาที จะได้ลิงก์เว็บไซต์จริง เช่น `https://your-project.vercel.app` ให้ใครก็เปิดดูได้ (แต่ข้อมูลจะเก็บแยกตามเบราว์เซอร์ของแต่ละคนตามที่อธิบายไว้ด้านบน)

## Deploy ขึ้น Netlify (ทางเลือก)

1. ทำขั้นตอน 1-2 เหมือนด้านบน (อัปขึ้น GitHub ก่อน)
2. ไปที่ [netlify.com](https://netlify.com) สมัคร/ล็อกอินด้วยบัญชี GitHub
3. กด **Add new site → Import an existing project** แล้วเลือก repository
4. ตั้งค่า Build command เป็น `npm run build` และ Publish directory เป็น `dist`
5. กด **Deploy site**

## โครงสร้างไฟล์

```
├── index.html          หน้าเว็บหลัก
├── package.json        รายการ library ที่ใช้
├── vite.config.js       ตั้งค่า build tool
└── src/
    ├── main.jsx         จุดเริ่มต้นของแอป
    └── App.jsx          โค้ดแดชบอร์ดทั้งหมด (แก้ไข/ปรับแต่งได้ที่นี่)
```

## ฟีเจอร์ที่มีอยู่แล้ว

- แดชบอร์ดภาพรวม: กราฟรับเข้า/เบิกจ่าย 14 วัน, รายการสินค้าที่ต้องเฝ้าระวัง
- พยากรณ์ & สั่งซื้อ: คำนวณความต้องการล่วงหน้า (7/14/30/60 วัน) เทียบกับสต๊อกคงเหลือ พร้อมคำแนะนำสั่งซื้อ
- ประวัติรับ-จ่าย: log ทุกรายการ ค้นหา/กรองได้
- นำเข้าข้อมูลจากไฟล์ Excel/CSV หรือลิงก์ Google Sheet ที่เผยแพร่เป็น CSV
  - รองรับทั้งไฟล์ที่ระบุ in/out ตรงๆ และไฟล์ที่มีแค่ตัวเลขคงเหลือ (ระบบคำนวณส่วนต่างเอง)
  - รองรับหัวคอลัมน์แบบ ERP/SAP เช่น Material Number, Available Qty ด้วย
